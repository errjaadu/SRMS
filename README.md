# Student Record Management System (SRMS)

## Build (Windows)
1. Install GCC (MinGW-w64) and make sure `gcc` is available in Command Prompt.
2. Open this folder in Command Prompt.
3. Run `build.bat`.
4. Start the program with `srms.exe`.

## Login
- Username: `admin`
- Password: `srms123`

## Import student records
SRMS imports records from a CSV file using the same format produced by its CSV export.

### Interactive menu
1. Choose **11. Import Records from CSV**.
2. Enter the CSV file path. Press Enter to use `students.csv` in the program folder.
3. The program validates each row before importing it.
4. Successfully imported records are saved to `students.dat`; the text and CSV exports are refreshed.

### Command line
After starting an administrator session, run:
```text
srms.exe --import
srms.exe --import "C:\\path\\to\\your\\file.csv"
```

## Export
- Menu option 10 creates/updates `students.txt` (readable report) and `students.csv` (re-importable data).
- The CSV contains all student fields and five subject/mark pairs.
- `srms.exe --export` updates both export files.

## Import behaviour and CSV rules
- Import **merges** records into the current database; it does not erase existing records.
- A student ID already in the database is skipped to avoid accidental duplicates.
- Invalid rows are skipped and reported; valid rows continue importing.
- The CSV must have the header and 18 columns generated by this SRMS.
- Names and text fields containing commas or quotation marks are supported when properly CSV-quoted.
- The program supports up to 500 student records.

Keep a backup of `students.dat` before replacing or moving your database. The supplied `srms.exe` from an older build is intentionally not included; rebuild from the updated source using `build.bat`.
